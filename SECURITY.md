# Политика безопасности

## Поддерживаемые версии

Проект носит образовательный характер и развивается в основной ветке. Обновления и исправления безопасности выпускаются для актуальной версии в ветке `master`.

| Версия | Поддержка |
| --- | --- |
| `master` (актуальная) | ✅ Поддерживается |
| Прочие ветки/теги | ❌ Не поддерживаются |

## Как сообщить об уязвимости

**Пожалуйста, не создавайте публичный Issue для сообщений об уязвимостях.**

Вместо этого:

1. Откройте вкладку **Security** репозитория.
2. Выберите **Report a vulnerability** (приватное сообщение об уязвимости).
3. Опишите проблему: условия воспроизведения, потенциальное влияние, при возможности — предложение по исправлению.

Альтернативно можно приватно обратиться к [@AOlifer](https://github.com/AOlifer).

## Сроки

- Подтверждение получения: в течение 5 рабочих дней.
- Первичная оценка и план действий: в течение 10 рабочих дней.
