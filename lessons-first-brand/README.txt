СНАЧАЛА УРОКИ! / lessons-first
Комплект графики приложения

КОНЦЕПЦИЯ
Раскрытая книга и направленный вверх ключ: знания открывают доступ к компьютеру.
Спокойная тёмная основа, сиреневый и лаймовый акценты.

ОСНОВНЫЕ ФАЙЛЫ
vector/app-icon.svg — квадратная иконка приложения; настоящий вектор.
icons/lessons-first.ico — Windows-иконка, 9 кадров: 16, 20, 24, 32, 40, 48, 64, 128, 256 px, RGBA.
vector/logo-light.svg — логотип для светлого фона, тёмная надпись.
vector/logo-dark.svg — логотип для тёмного фона, светлая надпись.
vector/logo-mono.svg — одноцветная версия.
vector/logo-horizontal.svg — горизонтальная компоновка для светлого фона.
vector/brand-mark.svg — отдельный знак для светлого фона, прозрачная подложка.
vector/brand-mark-dark.svg — отдельный знак для тёмного фона.
vector/brand-mark-mono.svg — одноцветный знак.
vector/logo-editable.svg — дополнительная версия с редактируемым текстом; нужен Segoe UI Bold.
backgrounds/lessons-first-background.png — фон без рекламных надписей; остаются учебные символы «А» и «+».
promo/lessons-first-promo.png — готовая рекламная обложка с текстом.
brand-preview.png — обзор иконки и логотипов на светлом и тёмном фоне.

ФОРМАТЫ И РАЗМЕРЫ
Все SVG, кроме явно обозначенного logo-editable.svg, состоят из векторных фигур и контуров. Растровых вставок и зависимостей от установленных шрифтов в них нет.
Логотипы в двух строках: SVG 1100 × 360, прозрачные PNG 2200 × 720.
Горизонтальный логотип: прозрачный PNG 2200 × 336.
PNG-иконки: 16, 20, 24, 32, 40, 48, 64, 128, 256, 512, 1024 px.
Отдельные знаки: PNG 1024 × 1024 с прозрачностью.
Фон и рекламная обложка: PNG 1672 × 941, исходный размер генерации. Это растровые иллюстрации, не вектор.

ИСПОЛЬЗОВАНИЕ
Для значка Windows/EXE используйте lessons-first.ico. SVG сохраняйте как масштабируемый мастер.
Для интерфейса WPF есть готовые PNG с прозрачностью. Логотип выбирайте по цвету фона.
Сохраняйте пропорции; вокруг знака и логотипа оставляйте свободное поле.
Рекламная обложка предназначена для описания проекта и анонсов. Фон без надписей можно использовать под собственный макет.

ПРОИСХОЖДЕНИЕ И ИСХОДНИКИ
Иконка и логотип нарисованы непосредственно в SVG. Буквы основных логотипов преобразованы из Segoe UI Bold в контуры.
Фон создан встроенным инструментом image_gen; рекламная обложка создана через image_gen на основе фона и иконки.
Полные промпты обоих изображений: source/image-prompts.txt.
Рекламная обложка — растровый макет; точные исходные векторные логотипы находятся в vector/.

ПРОВЕРЕНО
Кириллица и знак восклицания, отсутствие обрезки букв, прозрачность PNG/ICO, различимость иконки при 16 и 32 px, отсутствие встроенного растра в основных SVG.
