# Руководство по участию (Contributing)

Спасибо за интерес к этому проекту! Любой вклад приветствуется — от исправления опечатки до нового материала.

## Как предложить изменения

1. Сделайте форк репозитория или создайте ветку от `master`:
   ```bash
   git checkout -b feature/my-change master
   ```
2. Внесите изменения и сделайте коммит с понятным сообщением.
3. Откройте Pull Request с описанием: что изменено и зачем.

## Оформление материалов

- Каждый урок/тема — в отдельной папке или файле.
- Следуйте структуре и стилю уже существующих материалов.
- Не переименовывайте и не перемещайте существующие файлы без необходимости — это ломает ссылки.

## Сообщения коммитов

Проект следует [Conventional Commits](https://www.conventionalcommits.org/ru/) — как в существующей истории: `feat:`, `fix:`, `chore:`, `docs:` и т.д.

- Примеры: `docs: добавить урок 5`, `fix: исправить подсчёт бонуса за сессию`.
- Одна логическая единица изменений — один коммит.

## Сообщения об ошибках и предложения

- Нашли ошибку — создайте Issue по шаблону «Сообщение об ошибке» (bug report).
- Есть идея — используйте шаблон «Запрос функции» (feature request).
- Прежде чем создавать Issue, проверьте, не создан ли уже похожий.

## Pull Request

- Один PR — одна логическая задача.
- Убедитесь, что репозиторий после ваших изменений остаётся консистентным.
- Отвечайте на замечания ревью — это нормальная часть процесса.

Спасибо, что помогаете проекту становиться лучше!
